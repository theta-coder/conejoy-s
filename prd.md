# Cone Joys Scroll Hero

## Product brief

Cone Joys is a flavour-first ice-cream landing experience. The page should make the menu memorable in a few seconds and let visitors explore one flavour at a time by scrolling.

## Goal

Create a single focused hero journey that:

- Shows the real Cone Joy's brand logo.
- Presents all 12 menu flavours.
- Changes the cone and flavour name only when the visitor scrolls.
- Never overlaps two cones or two flavour labels.
- Works on phones, tablets, laptops, and large desktop screens.
- Gives a direct WhatsApp ordering path.

## Audience

Local ice-cream customers browsing on mobile first, with a secondary desktop audience. The experience should be understandable without technical knowledge and should load as a static HTML page through Live Server or any basic web server.

## Menu flavours

1. Mango
2. Kulfa
3. Chocolate Chip
4. Black Currant
5. Caramel Crunch
6. Tutti Frutti
7. Coffee Chino
8. Pista
9. Vanilla
10. Strawberry
11. Coconut Delight
12. Kit Kat

Prices, cup sizes, shakes, slush, and delivery details are outside this hero-only scope.

## User journey

1. Visitor sees the logo, headline, first cone, and “Scroll to taste” cue.
2. Visitor scrolls through a pinned hero journey.
3. Each scroll segment activates exactly one cone, one flavour name, one counter, and one background colour.
4. Visitor can select “Get this scoop” or “Order online” to open WhatsApp.

## Success criteria

- All 12 flavours are discoverable in order.
- Exactly one cone has visible opacity and visibility at a time.
- No horizontal overflow at any supported viewport.
- The CTA remains reachable without requiring the visitor to find a hidden menu.
- Images have meaningful alt text and a fallback asset if a file fails.
- Reduced-motion users receive a stable, non-moving version.

## Out of scope

- Checkout, cart, inventory, authentication, payments, CMS, and admin screens.
- Automated carousel or background autoplay.
- Pricing claims not present in the approved menu.
